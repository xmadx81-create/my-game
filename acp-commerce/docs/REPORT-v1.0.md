- 작성일: 2026-11-25
- 범위: 최초 작업 1~7항 (공식 문서 분석, 환경 확인, 수요·경쟁 조사, 난이도·수익성 비교, MVP 3종 개발, 모의 거래 검증, 관제 시스템)

## 1. 결론

| 구분 | 결과 |
|---|---|
| 개발 | 데이터 정제·변환·검수 3종 MVP와 통합 관제 화면 개발을 마쳤습니다. 외부 비용과 AI 호출비는 모두 0원입니다. |

## 2. 공식 ACP 개발 문서·저장소 분석

| 저장소/패키지 | 최신 버전(최종 갱신) | 상태 | 판단 |
|---|---|---|---|
| `@virtuals-protocol/acp-cli` | 1.0.40 (2026-10-05) | **현행 공식** | 채택 |
| `@virtuals-protocol/acp-node-v2` | 0.1.15 (2026-10-05) | 현행 SDK (CLI 내부 사용) | 간접 사용 |
| `@virtuals-protocol/acp-node` (v1) | 0.3.0-beta.40 | 폐기(deprecated, v2로 이전 안내) | 미사용 |
| `openclaw-acp` | 2026-06-01 | 폐기(acp-cli로 이전 안내) | 미사용 |
| `acp-python` | 2026-03-04 | PyPI 미배포·갱신 중단 | 미사용 |

주요 구조는 다음과 같습니다.

- **거래 상태:** `open → budget_set → funded → submitted → completed / rejected / expired`
- **판매자 동작:** 이벤트 스트림(`acp events listen/drain`) → `provider set-budget` → `provider submit`
- **납품물:** 본문은 ACP API에 오프체인 저장되고, 해시만 온체인에 기록됩니다.
- **확인된 제약:** 현행 CLI에는 provider용 reject 명령이 없습니다. 이를 반영해 "예산 제시 전 사전검증" 구조로 설계했습니다.
- **오퍼링명:** 온체인 job description에만 존재하고 이벤트 라인에는 포함되지 않습니다. 이를 반영해 요구사항 구조와 job 목록 조회를 함께 써서 서비스를 판별하도록 했습니다.

## 11. 가스비 대납(Gas Sponsorship) 확인

**정의:** 블록체인 거래에는 수수료(가스비)가 붙습니다. 이 가스비를 사용자 지갑 대신 플랫폼(Virtuals)이나 페이마스터(Paymaster) 계약이 내주는 방식을 가스비 대납이라고 합니다. ACP 에이전트 지갑은 Alchemy 스마트 계정(ERC-4337) 구조라서 거래가 UserOperation 형태로 전송되고, 가스비는 페이마스터가 처리합니다.

| 거래 유형 | 경로 (공식 SDK `acp-node-v2` 0.1.15 소스) | 가스비 부담 | 근거 |
|---|---|---|---|
| ACP 거래 (가격 제시·입금·납품·완료) | Virtuals 서버 `/wallets/alchemy-rpc` 경유 | **Virtuals 대납으로 추정** (서버 정책이라 클라이언트 코드로는 확정 불가 → 확인 필요) | 일반 송금과 별도 경로로 분리되어 있음 |
| 일반 송금·토큰 발행 등 | `/wallets/alchemy-rpc-erc20` 경유 | **에이전트가 ERC-20(USDC 등)으로 지불** | 공식 SKILL.md: "gas is charged in an ERC-20, not ETH, so a completely empty wallet fails" |
| Solana ACP 거래 | Kora 대납 노드 | ACP 프로그램 관련 거래만 대납 | SDK 주석: "Sponsorship covers ACP actions" |
| 로그인 메시지 서명 | 온체인 거래 아님 | 가스비 없음 | `acp-auth:<시각>` 메시지 서명 |

**사업 영향:**
- 판매자(provider)의 주요 동작(가격 제시·납품)은 ACP 거래에 속하므로 가스비 부담이 없을 가능성이 높습니다. 잔액 0원 상태에서도 판매 흐름이 가능할 수 있습니다.
- 다만 ERC-8004 신원 등록처럼 ACP 외 거래는 USDC 잔액이 필요할 수 있습니다.
- 소액 상품(0.20 USDC)의 수익성은 대납 여부에 크게 좌우되므로, 첫 실거래 시 가스비 발생 여부를 반드시 실측해야 합니다.
